Необходимо добавить функционал аудио- и видеозвонков 1-на-1 в личные чаты ([citizenId].tsx) на базе WebRTC и WebSocket.

1. УСТАНОВКА ЗАВИСИМОСТЕЙ:
   - Для Expo/React Native установи WebRTC библиотеку: npx expo install react-native-webrtc.
   - Если используется веб-версия, используй стандартный браузерный API navigator.mediaDevices.getUserMedia и RTCPeerConnection.

2. СИГНАЛИЗАЦИЯ ЧЕРЕЗ WEBSOCKET (БЭКЕНД И КЛИЕНТ):
   - Расширь имеющийся WebSocket-сервер для обработки событий звонка (Signaling Protocol):
     - call:offer — отправка предложения о звонке (SDP offer + тип: audio/video)
     - call:answer — ответ на звонок (SDP answer)
     - call:ice-candidate — обмен сетевыми кандидатами WebRTC
     - call:reject / call:end — отклонение или завершение вызова
     - call:busy — статус "Занято", если пользователь уже в другом звонке

3. ИНТЕРФЕЙС ИКРАНА ЗВОНКА (Call Screen / Modal):
   - В шапку чата ([citizenId].tsx) добавь 2 иконки: 📞 (Аудиозвонок) и 📹 (Видеозвонок).
   - Создай UI полноэкранного модального окна звонка (CallScreen.tsx):
     - Показ аватарки, имени и статуса ("Вызов...", "Соединение...", "00:15").
     - Окно локального видео (маленький оверлей) и окно удаленного видео (на весь экран) для видеозвонков.
     - Кнопки управления:
       - 🔇 Вкл/Выкл микрофон (track.enabled)
       - 📷 Вкл/Выкл камеру / Переключение камеры (front/back)
       - 🔊 Переключение динамика (Loudspeaker/Earpiece)
       - 🔴 Красная кнопка завершения вызова.
   - Создай UI входящего вызова (Incoming Call Banner / Screen) с кнопками «Принять» (зеленая) и «Отклонить» (красная) + звуковой сигнал вызова.

4. ЛОГИКА WEBRTC (webrtcService.ts):
   - Реализуй менеджер PeerConnection:
     - Инициализация RTCPeerConnection с публичными STUN-серверами (например, stun:stun.l.google.com:19302).
     - Запрос разрешений на микрофон и камеру перед началом вызова.
     - Корректная очистка медиапотоков (stop tracks), закрытие peerConnection и сброс состояния при завершении звонка.

Реализуй систему сигнализации вызова через WebSocket, окно входящего/исходящего звонка и установи WebRTC соединение.
