Суть ошибки видна прямо на красном экране:

> **`expo-notifications: Android Push notifications ... was removed from Expo Go with the release of SDK 53.`**

### 💡 В чём проблема?

Начиная с **Expo SDK 53**, команда Expo полностью **удалила поддержку push-уведомлений из приложения Expo Go** для Android.

Как только код делает `import * as Notifications from 'expo-notifications'` в файле `timeutils.tsx` (строка 19), Expo Go на смартфоне моментально падаeт с этой фатальной ошибкой (`Uncaught Error`).

---

### 🛠️ Как это исправить?

Чтобы приложение снова работало в **Expo Go** без сбоев, необходимо сделать **безопасный импорт (safe wrapper)** или временно приглушить/обернуть инициализацию уведомлений, если приложение запущено внутри Expo Go (`Constants.appOwnership === 'expo'`).

Отправьте Replit этот готовый промпт для автоматического исправления:

// Check if app is running inside Expo Go client
export const isExpoGo = Constants.appOwnership === 'expo';

let Notifications: typeof import('expo-notifications') | null = null;

// Only load expo-notifications dynamically if NOT running in Expo Go OR wrap calls safely
if (!isExpoGo) {
  try {
    Notifications = require('expo-notifications');
  } catch (e) {
    console.warn('Notifications module could not be loaded:', e);
  }
}

// Wrapper for scheduling or pushing local/remote notifications
export async function safeScheduleNotification(options: any) {
  if (isExpoGo) {
    console.log('[Expo Go Guard] Notification suppressed in Expo Go mode:', options);
    return;
  }
  if (Notifications) {
    return await Notifications.scheduleNotificationAsync(options);
  }
}
