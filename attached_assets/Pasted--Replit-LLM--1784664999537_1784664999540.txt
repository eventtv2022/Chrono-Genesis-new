### Промт для Replit: Создание P2P Мессенджера TimeNation (Mobile)

**Роль:** Ты — ведущий Full-stack разработчик мобильных приложений (React Native / Flutter), специализирующийся на децентрализованных технологиях (P2P), криптографии и безопасных протоколах связи.

**Задача:** Спроектировать и разработать программный модуль P2P-мессенджера для граждан TimeNation, интегрированный в существующее мобильное приложение (TimeNation Mobile). Мессенджер должен работать полностью автономно, без центрального сервера, обеспечивая максимальную конфиденциальность и безопасность.

#### Основные Требования и Функциональность:

**1. Децентрализованная Архитектура (P2P):**

* Реализуй связь напрямую между устройствами пользователей (peer-to-peer).
* Используй современный P2P-протокол (например, libp2p, Matrix DHT, или протокол на основе Noise Protocol Framework) для обнаружения пиров и маршрутизации сообщений.
* Реализуй механизм хранения зашифрованных сообщений на устройствах пользователей и временное кширование на доверенных пирах (dht) для доставки сообщений офлайн-пользователям.

**2. Безопасность и Конфиденциальность (Security first):**

* **Сквозное шифрование (E2EE):** Все сообщения (текст, файлы, метаданные звонков) должны шифроваться на устройстве отправителя и дешифроваться только на устройстве получателя. Используй проверенные библиотеки (например, Signal Protocol, Matrix Olm/Megolm).
* **Управление ключами:** Разработай систему генерации, хранения (в защищенном хранилище устройства, например, Secure Enclave/Keystore) и обмена публичными ключами между пользователями при первом контакте.
* **Анонимность:** Минимизируй сбор метаданных. IP-адреса не должны быть публично доступны.

**3. Гражданская Идентификация и Учет времени:**

* Интегрируй систему мессенджера с модулем `embassyNodes.ts` (идентификация граждан и паспорта). Пользователи должны авторизоваться, используя свои гражданские ключи TimeNation.
* Реализуй отображение гражданского статуса и рейтинга репутации собеседника.

**4. Интеграция DARMIN (Внутренняя Экономика):**

* **Микротранзакции:** Реализуй возможность отправки DARMIN напрямую в чате (модуль `deals.ts`).
* **Платные функции (опционально):** Предусмотри возможность взимания небольшой комиссии в DARMIN за отправку больших файлов или создание публичных каналов (для предотвращения спама). Комиссия должна распределяться между пирами, обеспечивающими доставку.

**5. Система Репутации:**

* Реализуй механизм оценки пользователей на основе их активности в мессенджере (спам, полезность, корректность).
* Интегрируй эту систему с общим рейтингом гражданина TimeNation. Оценки должны быть зашифрованы и подтверждаться через DHT.

**6. Функциональность Чата:**

* **Текстовые сообщения:** Статус доставки/прочтения (децентрализованный).
* **Обмен файлами:** Децентрализованная передача файлов (P2P) с шифрованием.
* **Групповые чаты:** Реализуй децентрализованный протокол групповых чатов (например, Matrix группы).
* **Аудио/Видеозвонки:** Используй WebRTC для установления прямого P2P соединения для звонков. Сигналинг должен идти через зашифрованный P2P канал.

**7. Мобильный Интерфейс (UI/UX):**

* Разработай интуитивно понятный и современный интерфейс для мобильного приложения (React Native/Flutter).
* Дизайн должен быть чистым, фокусироваться на приватности. Используй цветовую схему, соответствующую TimeNation (возможно, как на слайдах — футуристичный синий/фиолетовый, но адаптированный для чтения).
* Реализуй быстрый поиск контактов среди граждан TimeNation.

**8. Тестирование и Документация:**

* Напиши модульные и интеграционные тесты для P2P логики, шифрования и UI.
* Подготовь подробную документацию по архитектуре, API модуля и протоколам безопасности.

**Вывод (Результат):** Ты должен предоставить полный исходный код модуля мессенджера, готовый к интеграции в мобильное приложение TimeNation, с рабочим демо, демонстрирующим отправку зашифрованных сообщений и DARMIN между двумя симулируемыми мобильными устройствами в P2P сети.
