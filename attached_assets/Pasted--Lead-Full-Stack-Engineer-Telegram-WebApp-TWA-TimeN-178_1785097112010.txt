2. ПОЛНЫЙ ФИКС ПОДПИСИ CANVAS (TOUCH / MOBILE)
- В CSS для #sig-canvas убедись в наличии:
  touch-action: none; user-select: none; -webkit-user-select: none; z-index: 10;
- Перепиши обработчики событий для подписи:
  * Для мобильных устройств (touch) используй события touchstart, touchmove, touchend с { passive: false }.
  * Вызывай e.preventDefault() во всех touch-событиях до любого другого кода.
  * Блокируй вертикальный свайп Telegram при рисовании: tg.disableVerticalSwipes() на touchstart и tg.enableVerticalSwipes() на touchend/touchcancel.
  * Явно задай стили линий при начале рисования: ctx.strokeStyle = '#000000'; ctx.lineWidth = 3; ctx.lineCap = 'round';
  * Рассчитывай координаты строго через getBoundingClientRect():
    const rect = canvas.getBoundingClientRect();
    const x = e.touches[0].clientX - rect.left;
    const y = e.touches[0].clientY - rect.top;
