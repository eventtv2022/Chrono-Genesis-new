## 3. PHOTO STYLE CONVERTER LOGIC (Python snippet)

Реализуй функцию `process_photo_to_official_style`, которая принимает загруженное изображение, удаляет фон и накладывает строго нейтральный светло-серый студийный фон.

```python
import os
from rembg import remove # Необходима библиотека rembg
from PIL import Image, ImageOps

def process_photo_to_official_style(input_path, output_path):
    """
    Преобразует любое фото пользователя в официальный формат ICAO (человек на сером фоне).
    """
    # 1. Загрузка исходного фото
    input_image = Image.open(input_path).convert("RGBA")
    
    # 2. Удаление фона (RemBG локальная сегментация)
    output_image = remove(input_image)
    
    # 3. Создание нового светло-серого фона (neutral grey)
    # Используем цвет ICAO-стандарта (напр., RGB 200, 200, 200)
    bg_color = (200, 200, 200, 255) 
    grey_background = Image.new("RGBA", input_image.size, bg_color)
    
    # 4. Наложение человека без фона на серый фон
    final_portrait = Image.alpha_composite(grey_background, output_image)
    
    # 5. Кадрирование ( cropping) и масштабирование
    # Кропаем изображение по центру, чтобы лицо было в фокусе (соотношение сторон для ID-карты)
    # (Добавь логику кропа под размер бланка)
    
    # 6. Сохранение в JPG
    final_portrait.convert("RGB").save(output_path, "JPEG")

```
