🔍 Ключевые несоответствия между Web и Mobile (Анализ кодовой базы)
Модуль Карт (ChronopediaMap):
Web: Работает напрямую через React-Leaflet с полной интеграцией событий клика, всплывающих окон и Zod-валидации с clamp-ограничителями.
Mobile: Реализован через обертку WebView, транслирующую JS-код внутрь нативного контейнера. Это создает задержки (latency) при передаче координат через мосты (postMessage) и рассинхронизацию интерфейса создания точки.
Дипломатический сектор и Ноды связи:
Web: Включает полную панель управления посольствами, отображение Аптайма и форму регистрации с универсальным инпутом (координаты + Plus Code).
Mobile: Ограничен базовым просмотром. Функционал Proof of Location (сканирование QR-кода на физическом узле связи с привязкой к нативному GPS датчику смартфона) описан в архитектуре, но не до конца увязан с нативным UI камеры.
Бесшовность ТВ-плеера:
Web: Использует HTML5 Video API с предзагрузкой (preload) следующего сегмента вещания.
Mobile: Нативные плееры в смартфонах по умолчанию блокируют автоматическое воспроизведение (autoplay) со звуком и пытаются открыть видео во весь экран, если не переданы специфические инлайновые пропсы (playsInline).
