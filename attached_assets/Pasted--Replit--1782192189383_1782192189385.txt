# REPLIT ACTUATOR: IMPLEMENT DYNAMIC AUDIO-DRIVEN VIDEO TIMINGS IN RENDER_SERVICE

## 1. OBJECTIVE

Провести глубокий рефакторинг пайплайна генерации видео в файле `artifacts/api-server/src/services/renderService.ts`. Нам необходимо полностью избавиться от жестко закодированного интервала сцен в 12 секунд (`SEGMENT_DURATION_SEC = 12`). Вместо этого длительность каждой из 5 сцен видеоряда и появление соответствующих субтитров должны динамически адаптироваться под реальную скорость речи, полученную из аудиофайлов Google TTS.

## 2. TECHNICAL SPECIFICATION & LOGIC FLOW

1. **Посегментный рендеринг аудио:** Изменить логику обработки текста манифеста. Массив `segments` (ровно 5 штук) должен обрабатываться последовательно. Для каждого текстового сегмента по отдельности вызывается функция `generateTTSBuffer(segmentText)`. Полученный буфер записывается на диск во временную папку `tmpDir` как `tts_seg_0.mp3`, `tts_seg_1.mp3` и т.д.
2. **Инспекция длительности через `ffprobe`:** Написать асинхронную функцию-хелпер `getAudioDuration(filePath: string): Promise<number>`, которая через `child_process.spawn` вызывает утилиту `ffprobe`:
```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 [filePath]

```



```
   Функция должна возвращать точную длительность аудиофайла в секундах (тип `number`).
3. **Расчет таймлайна (Timeline Сoordinates):** Сформировать массив реальных длительностей `const durations = [d0, d1, d2, d3, d4]`. На его основе рассчитать накопительные точки смещения для переходов видео и показа текста:
   - Сцена 0: `start = 0`, `end = d0`
   - Сцена 1: `start = d0`, `end = d0 + d1`
   - Сцена $i$: `start = текущий_офсет`, `end = текущий_офсет + d_i`
4. **Динамическая склейка в FFmpeg (Complex Filter):**
   - **Аудио:** Склеить 5 временных файлов `tts_seg_X.mp3` в один аудиопоток с помощью фильтра `concat=n=5:v=0:a=1` или через команду предварительной склейки файлов.
   - **Видео (Провайдеры фона):** Передать высчитанные точки смещения в фильтр переходов `xfade`. Параметр `offset` для перехода к следующей сцене должен строго равняться сумме длительностей всех предыдущих сцен.
   - **Субтитры:** В макросах фильтра `drawtext` для каждого сегмента текста жестко прописать динамические интервалы отображения: `enable='between(t, start_time, end_time)'`.
5. **Общий хронометраж:** Итоговая длительность выходного `.mp4` файла должна динамически подстраиваться под общую сумму длин всех аудио-сегментов (вместо фиксированных 60 секунд).
```
