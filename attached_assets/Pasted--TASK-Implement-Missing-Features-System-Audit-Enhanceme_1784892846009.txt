### 2. Complete Missing Module Endpoints
Implement express routes for schema tables that currently lack API coverage:
- **Timeline Capsules (`/api/timeline-capsules`)**:
  - `POST /api/timeline-capsules` — Create/store a temporal capsule anchored to `timelineCoord`.
  - `GET /api/timeline-capsules?citizenId=X` — Retrieve citizen's temporal capsules.
- **Time Bank & Ledger (`/api/time-bank`)**:
  - `POST /api/time-bank/loans` — Request a time loan against collateral.
  - `POST /api/time-bank/loans/:id/repay` — Manual repayment of loan, logging entry into `time_bank_ledger`.
  - `GET /api/time-bank/ledger?citizenId=X` — Fetch ledger audit history.
- **TV Slots & Capsules (`/api/tv`)**:
  - `GET /api/tv/slots?date=YYYY-MM-DD` — Get 1440 minute slots schedule.
  - `POST /api/tv/slots/:id/book` — Book TV slot with Timeltr or Fiat payment status.
  - `POST /api/tv/capsules` — Create broadcast capsule tied to a booked TV slot.
