Для того чтобы ваш фронтенд-разработчик (или агент в Replit) идеально реализовал двойное отображение времени (локальное + UTC), промт должен содержать четкое техническое ТЗ по обработке временных меток.

Вот промт, который гарантирует корректное отображение времени в интерфейсе:

---

# REPLIT ACTUATOR: MODULE "TIME_DISPLAY_ENGINE"

## 1. OBJECTIVE

Реализовать в интерфейсе TimeNation блок отображения времени, который исключает путаницу между локальным временем Гражданина и глобальным временем Системы (UTC).

## 2. FRONTEND DISPLAY REQUIREMENTS (UI/UX)

Приложение должно отображать два блока времени в верхней панели (Header) или в карточке бронирования:

1. **Local Time (Локальное время):** - Формат: `HH:MM:SS` (например, `18:00:00`).
* Использование: Отражает текущее время устройства пользователя (на основе `Intl.DateTimeFormat().resolvedOptions().timeZone`).
* Визуальный стиль: Крупный, основной шрифт. Подпись: "Local Time".


2. **System Time (UTC):**
* Формат: `HH:MM:SS` (например, `12:00:00`).
* Использование: Синхронизируется с сервером через эндпоинт `/api/v1/system/time`.
* Визуальный стиль: Меньший шрифт, моноширинный. Подпись: "UTC Time".



## 3. TECHNICAL IMPLEMENTATION (JS/TS logic)

* **Синхронизация:** Каждую секунду вызывать функцию обновления `setInterval`, которая:
* Берет текущее локальное время.
* Получает актуальное UTC время (с учетом возможного дрейфа клиентских часов, периодически сверяясь с `/api/v1/system/time`).


* **Бронирование слотов:** При выборе минуты в календаре, приложение должно подсвечивать слот, используя **UTC-индекс минуты** (0-1439).
* **User Feedback:** Если разница между локальным временем и UTC отображается корректно, добавить индикатор синхронизации (зеленая точка), подтверждающий, что клиент находится в «петле» сервера.

## 4. EXAMPLE COMPONENT LOGIC

```javascript
// Псевдокод логики компонента
const now = new Date();
const localTime = now.toLocaleTimeString(); // Локальное время пользователя
const utcTime = now.toUTCString().split(' ')[4]; // Время по Гринвичу

```

## 5. EXPECTED UI OUTPUT

* Пользователь видит: `18:00:00 (Local)` и `12:00:00 (UTC)`.
* При нажатии на календарь, система должна показывать, что бронирование происходит на `UTC-минуту`.
