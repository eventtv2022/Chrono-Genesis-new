# REPLIT ACTUATOR: INTEGRATED TIMETR DISCUSSION SUITE WITH LIVE APP-STATE TIMER & IMAGE UPLOADS

## 1. OBJECTIVE

Модернизировать экран TiMETR (`artifacts/mobile/app/(tabs)/timetr.tsx`), внедрив систему сквозного обсуждения сделок между заказчиком и исполнителем прямо внутри текущего профиля (без перехода на другие вкладки). Интегрировать в интерфейс живой таймер контроля выполнения задачи с автоматической паузой при сворачивании приложения (`AppState`) и функционал загрузки изображений (референсы от заказчика и результаты от исполнителя).

## 2. DATABASE SCHEMA CHANGES (`lib/db/src/schema/`)

1. **Таблица сообщений (`chat_messages`):** Убедиться в наличии или создать таблицу со следующей структурой:
* `id`: serial/uuid (PK)
* `contractId`: references `time_bank_contracts.id` (связка с конкретной сделкой)
* `senderId`: references `citizens.id`
* `messageText`: text
* `imageUrl`: text (null) — ссылка на загруженное фото (референс/результат)
* `createdAt`: timestamp


2. **Расширение таблицы контрактов/логов времени:** Добавить поля для трекинга:
* `timerStatus`: text (enum: 'stopped', 'running', 'paused')
* `totalTrackedMinutes`: integer (default 0) — накопленное "чистое" время работы исполнителя в активном окне приложения.



## 3. TECHNICAL SPECIFICATION & COMPONENT LOGIC

### А. Интерфейс Обсуждения в "Одно Окно" (`timetr.tsx`)

* Добавить всплывающее модальное окно (или раскрывающийся `BottomSheet`) `DiscussionModal` прямо внутри экрана TiMETR.
* Модал активируется по кнопке-иконке «Обсудить / Чат» на карточке любой сделки (как предварительной, так и активной).

### Б. Умный Таймер Хронометража (`AppState` Integration)

* Для исполнителя внутри чата сделки отображается панель управления: `[ ▶ Начать работу ]`, `[ ⏸ Пауза ]`, `[ 🏁 Завершить работу ]`.
* Реализовать нативный хук `AppState` из `react-native`. Если статус таймера `'running'` и `AppState.currentState` переходит в `background` или `inactive` (пользователь свернул приложение, заблокировал экран или перешел на другую вкладку), таймер автоматически ставится на паузу (`'paused'`), фиксируя время. При возвращении в статус `active` — отсчет чистого времени возобновляется.

### В. Модуль Фотофиксации (`Expo ImagePicker`)

* Внутри чата рядом с полем ввода текста добавить кнопку «Прикрепить фото» (иконка камеры/скрепки).
* Интегрировать библиотеку `expo-image-picker` для возможности сделать снимок с камеры в реальном времени или выбрать референс из галереи.
* Настроить бэкенд-эндпоинт `POST /api/chats/upload` для сохранения картинок и записи `imageUrl` в базу данных. В ленте чата отображать изображения в виде аккуратных превью.

### Г. Закрытие петли обратной связи ИИ

* При нажатии исполнителем кнопки `[ 🏁 Завершить работу ]`, итоговое значение `totalTrackedMinutes` отправляется на бэкенд в функцию двойного хронометража `recordActualTime(contractId, actualMinutes)`. ИИ-Аудитор автоматически рассчитывает погрешность (`deviationPercent`) плана и факта для калибровки личного тарифа специалиста.
