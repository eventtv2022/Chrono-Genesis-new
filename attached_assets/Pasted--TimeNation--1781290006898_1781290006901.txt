Для проекта **TimeNation** стратегически важны **оба варианта**, но внедрять их нужно в правильной последовательности. Сейчас у вас «живой» продукт, и критическая уязвимость (когда гражданин теряет паспорт навсегда при закрытии вкладки) требует немедленного и самого отказоустойчивого решения.

Давайте выберем приоритет и скорректируем промт для Replit.

## Что нужнее прямо сейчас?

### 🥇 Выбор №1 (Срочный): Страница «Мой паспорт» по номеру ID

**Почему это приоритет:** Это решение на 100% автономно и не зависит от внешних факторов. Вам не нужно регистрировать аккаунты в SendGrid/Resend, привязывать туда домены, настраивать DNS-записи (SPF, DKIM) и платить за тарифы. Replit-агент сможет собрать эту страницу **за 5 минут**, и у граждан *сразу* появится гарантированный доступ к своим документам.

### 🥈 Выбор №2 (Второй этап): Email-нотификация

**Почему это нужно сделать позже:** Email — это отличный UX и официальный тон. Но если у вас отвалится баланс на SendGrid или письмо уйдет в спам, пользователь все равно потеряет паспорт. Поэтому Email должен стать *дополнением* к публичной странице поиска.

## Готовый промт для Replit: Реализация страницы «Мой паспорт» и сохранение ссылок

Этот промт заставит агента создать защищенное хранилище ссылок в базе данных и запустить публичный инструмент восстановления ID-карт по номеру.

---

# REPLIT ACTUATOR: IMMUTABLE PASSPORT STORAGE & PUBLIC LOOKUP PAGE

## 1. OBJECTIVE

Исправить критическую потерю доступа к сгенерированным документам. Необходимо сохранять финальные ссылки на ID-карту и паспорт в PostgreSQL, а также создать простую публичную страницу восстановления доступа по номеру Гражданина (`citizen_id`).

## 2. DATABASE UPDATE (PostgreSQL Persistent Storage)

Убедись, что в таблице `citizens` есть поля для постоянного хранения ссылок на отрендеренные файлы. Они не должны генерироваться «на лету» только для экрана регистрации.

```sql
ALTER TABLE citizens ADD COLUMN IF NOT EXISTS id_card_url VARCHAR(512);
ALTER TABLE citizens ADD COLUMN IF NOT EXISTS passport_pdf_url VARCHAR(512);

```

*Когда статус гражданина меняется на `issued` и PIL завершает наложение данных на макет `image_25.png`, пути к готовым файлам (например, `/storage/passports/id_000000003.jpg`) должны жестко записываться в эти поля.*

---

## 3. BACKEND ROUTER FOR PUBLIC LOOKUP (FastAPI)

Реализуй публичный эндпоинт, который принимает номер гражданина, проверяет его существование и отдает ссылки на файлы.

```python
@app.get("/api/v1/citizens/lookup/{document_id}")
async def lookup_citizen_documents(document_id: str, db: Session = Depends(get_db)):
    # Приводим строку вида '000000003' или '3' к чистому Integer ID
    try:
        clean_id = int(document_id.lstrip('0'))
    except ValueError:
        raise HTTPException(status_code=400, detail="Неверный формат номера ID")
        
    citizen = db.query(Citizen).filter(Citizen.id == clean_id).first()
    
    if not citizen:
        raise HTTPException(status_code=404, detail="Гражданин с таким номером не найден в реестре")
        
    if not citizen.id_card_url or not citizen.passport_pdf_url:
        return {
            "status": "processing",
            "message": "Документы находятся на этапе генерации. Пожалуйста, подождите."
        }
        
    return {
        "status": "success",
        "surname": citizen.surname,
        "given_names": citizen.given_names,
        "id_card_url": citizen.id_card_url,
        "passport_pdf_url": citizen.passport_pdf_url
    }

```

## 4. FRONTEND IMPLEMENTATION: PAGE "MY PASSPORT" (Tailwind CSS)

Создай новый роут / новый файл страницы `passport-lookup.html` (или компонент в Expo/React). Дизайн должен соответствовать строгому стилю TimeNation:

* **Элементы ввода:** Одно лаконичное поле: `ВВЕДИТЕ НОМЕР ГРАЖДАНЫНА (9 цифр)`. Кнопка `ПОЛУЧИТЬ ДОКУМЕНТЫ`.
* **Логика вывода:** При успешном ответе от API, форма скрывается, и перед пользователем появляются две крупные кнопки: `СКАЧАТЬ ID-КАРТУ (PNG)` и `СКАЧАТЬ ПАСПОРТ ICAO (PDF)`. Также выводится мини-карточка с подтверждением ФИО владельца, чтобы исключить подбор чужих номеров наугад.
