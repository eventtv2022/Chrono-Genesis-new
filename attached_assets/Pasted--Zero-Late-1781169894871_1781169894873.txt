Я:
ИНФРАСТРУКТУРА ХРАНЕНИЯ ВИДЕО (ТРЕХКОНТУРНАЯ СИСТЕМА)
Для обеспечения нулевой задержки (Zero Latency) и неограниченного масштабирования, файлы контента физически изолированы от сервера Replit:
Контур «Горячий» (Вещание/Стриминг):
Технология: AWS S3 (или DigitalOcean Spaces) + Cloudflare CDN.
Назначение: Кэширование и мгновенная раздача HLS (.m3u8) / MP4 потоков Граждан в реальном времени по всему миру.
Контур «Холодный» (Архив):
Технология: Google Cloud Storage / Backblaze B2.
Назначение: Долгосрочное и дешевое хранение архивных записей прошедших минут эфира.
Контур «Метаданные» (БД):
Технология: PostgreSQL.
Назначение: Хранение текстовых ссылок на файлы, ID Граждан и временных меток. Код в Replit оперирует только ссылками.
3. СХЕМА БАЗЫ ДАННЫХ (POSTGRESQL / APPEND-ONLY)
Добавляется системная таблица расписания эфира, жестко завязанная на 1440 минут в сутках:
SQL
CREATE TABLE broadcast_slots ( id SERIAL PRIMARY KEY, slot_date DATE NOT NULL, -- Дата эфира minute_of_day INT NOT NULL, -- Индекс минуты в сутках (0-1439) citizen_id VARCHAR(255) NOT NULL, -- ID Гражданина-вещателя video_url VARCHAR(512) NOT NULL, -- Ссылка на видео в CDN (S3) manifest_id INT, -- Ссылка на сгенерированный ИИ Манифест cost_darmin NUMERIC(10, 2) NOT NULL, -- Стоимость слота tax_darmin NUMERIC(10, 2) NOT NULL, -- Удержанный налог (2%) status VARCHAR(50) DEFAULT 'scheduled' -- scheduled, live, passed ); -- Защита от двойного бронирования одной и той же минуты суток ALTER TABLE broadcast_slots ADD CONSTRAINT unique_slot_per_day UNIQUE (slot_date, minute_of_day); 
4. СДВОЕННЫЙ ДВИЖЕК: MANIFEST & CHRONOS-CAST (FASTAPI)
А. Модуль генерации манифестов (manifest_engine)
Интегрирует Google Gemini API (через ключ из Replit Secrets) для генерации идеологического контента, который конвертируется в NFT-капсулы времени.
Б. Модуль вещания минуты эфира (broadcast_engine)
Обеспечивает поминутную сетку вещания и автоматическое удержание налога Казначейства.
Python
