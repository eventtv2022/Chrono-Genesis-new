## 2. REPAIRING PHOTO GENERATION ENGINE (Under the Hood Fix)

Проблема с генерацией фото обычно связана с тем, что скрипт либо не удаляет фон правильно, либо падает при наложении слоев (альфа-композиция). Необходимо жестко прописать логику обработки.

**Найди файл `photo_engine.py` (или соответствующий модуль бэкенда) и примени эту логику:**

```python
import os
import io
from PIL import Image, ImageOps
import requests # Если используете remove.bg API

def process_photo_to_icao_standard(input_image_path, output_path):
    """
    Принимает любое фото пользователя. Вырезает фон (ИИ), 
    накладывает нейтральный серый фон ICAO и кропает под паспорт.
    """
    try:
        # 1. ЗАГРУЗКА И ВАЛИДАЦИЯ (Исправление падений при чтении)
        with open(input_image_path, "rb") as f:
            input_image_data = f.read()
        user_image = Image.open(io.BytesIO(input_image_data)).convert("RGBA")

        # 2. ИИ-ВЫРЕЗАНИЕ ФОНА (Здесь был баг)
        # ВАРИАНТ А: remove.bg API (Надежный, платный)
        # api_key = os.getenv("REMOVE_BG_API_KEY")
        # if not api_key: raise Exception("Missing API Key")
        # response = requests.post(
        #     'https://api.remove.bg/v1.0/removebg',
        #     files={'image_file': input_image_data},
        #     data={'size': 'auto'},
        #     headers={'X-Api-Key': api_key},
        # )
        # if response.status_code == 200:
        #     processed_image_bytes = response.content
        #     object_no_bg = Image.open(io.BytesIO(processed_image_bytes)).convert("RGBA")
        # else: raise Exception(f"AI removal failed: {response.text}")

        # ВАРИАНТ Б (Используем его для локального Replit): Используем локальную библиотеку 'rembg'
        from rembg import remove # <--- Обязательно добавить в pyproject.toml
        object_no_bg = remove(user_image)

        # 3. НАЛОЖЕНИЕ НА ОФИЦИАЛЬНЫЙ СЕРЫЙ ФОН ICAO
        icao_grey_color = (200, 200, 200, 255) # Светло-серый
        grey_background = Image.new("RGBA", object_no_bg.size, icao_grey_color)
        final_portrait = Image.alpha_composite(grey_background, object_no_bg)

        # 4. ФИНАЛЬНЫЙ КРОП И МАСШТАБИРОВАНИЕ (Под размер рамки документа, напр. 300x400)
        # Делаем умный кроп, чтобы лицо было в фокусе (Face-Aware Crop, можно добавить Dlib или MediaPipe)
        # Для простоты используем центрированный кроп
        final_icao_photo = ImageOps.fit(final_portrait, (300, 400), Image.Resampling.LANCZOS)
        
        # 5. СОХРАНЕНИЕ
        final_icao_photo.convert("RGB").save(output_path, "JPEG")
        return True

    except Exception as e:
        print(f"CRITICAL ERROR IN PHOTO ENGINE: {e}")
        # Создаем пустую серую заглушку, чтобы бэкенд не падал дальше
        dummy_photo = Image.new("RGB", (300, 400), (200, 200, 200))
        dummy_photo.save(output_path, "JPEG")
        return False

```
