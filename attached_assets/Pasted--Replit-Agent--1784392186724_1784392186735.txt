### Prompt для Replit Agent: Реализация фичи "Social Alarm" с Гимном TimeNation (Расширенная логика)

**Задача:**
Реализовать фичу "Social Alarm" (Социальный Будильник) для платформы TimeNation. Фича должна работать синхронно в **веб-версии** и в **мобильной версии** приложения, встраиваться в существующую **вкладку «Время»** (где уже есть таймер и обычный будильник) и поддерживать локализацию на **все 24 языка** платформы.

**Главное изменение в логике:** Запустить будильник/тревогу (вызвать одновременное включение Гимна TimeNation) может **как администратор** (`gov_role === 'admin'`), так и **любой обычный пользователь**, пригласив к участию другого конкретного пользователя или группу пользователей (из числа тех, кто дал предварительное согласие).

---

### Шаг 1: Обновление схемы Базы Данных (Drizzle ORM)

1. В таблицу `citizens` (`lib/db/src/schema/citizens.ts`) добавить поле глобального согласия:
* `social_alarm_consent`: `integer` (или `boolean`), по умолчанию `0` (нет согласия). Пользователь должен включить его, чтобы другие могли отправлять ему «социальный будильник».


2. Создать или обновить таблицу `social_alarms` для логирования вызовов:
* `id`: `serial` primary key
* `initiated_by`: `integer` references `citizens.id` (кто запустил)
* `target_type`: `text` (`'all'` для админов, `'direct'` для обычных пользователей)
* `created_at`: `timestamp` с default now.


3. Создать связующую таблицу `social_alarm_targets` (если будильник направлен конкретным людям):
* `alarm_id`: `integer` references `social_alarms.id`
* `target_citizen_id`: `integer` references `citizens.id`



---

### Шаг 2: Бэкенд и WebSockets (Real-time & Права доступа)

1. **Эндпоинт настроек:** PATCH/POST рут в `routes/citizens.ts` для переключения флага `social_alarm_consent`.
2. **WebSocket Архитектура:**
* При подключении к сокет-серверу каждый пользователь (веб/мобильный) автоматически подписывается на свою персональную комнату (например, `room_citizen_[id]`).
* Если у пользователя `social_alarm_consent === 1`, сервер также добавляет его сокет в глобальный канал `social_alarm_global_subscribers`.


3. **Эндпоинт запуска будильника (POST `/api/system/trigger-alarm`):**
* **Сценарий 1 (Админ):** Если у отправителя `gov_role === 'admin'`, он может сделать глобальный пуш. Сервер отправляет событие `PLAY_ANTHEM` через WebSocket-канал `social_alarm_global_subscribers`.
* **Сценарий 2 (Любой пользователь):** Любой авторизованный пользователь может передать массив `targetCitizenIds`. Бэкенд проверяет по БД, что у этих таргетов `social_alarm_consent === 1`, и отправляет событие `PLAY_ANTHEM` точечно в их персональные сокет-комнаты.


4. **i18n:** Добавить ключи для всех 24 языков (переводы кнопок, оверлеев и списков).

### Шаг 3: Кроссплатформенный Фронтенд (React / TypeScript / Tailwind)

1. **Интеграция во вкладку «Время»:**
* Внутри вкладки «Время» (рядом с таймером) создать блок **«Социальный Будильник»**.
* Добавить UI-переключатель (Toggle): *"Разрешить другим пользователям будить меня Гимном TimeNation"* (локализация на 24 языка).
* Добавить интерфейс инициации: поле поиска/выбора пользователей платформы (у которых включен этот флаг) и кнопку **«Пригласить к участию (Включить Гимн)»**.


2. **Адаптивность (Веб + Мобильная версия):**
* Интерфейс во вкладке «Время» должен быть полностью адаптивным (Mobile-first, корректный тач-интерфейс для смартфонов и читаемость на десктопе).


3. **Логика воспроизведения и Обход Autoplay Policy:**
* Настроить фоновый сокет-листенер. При получении события `PLAY_ANTHEM` инициировать воспроизведение `/assets/audio/timenation_anthem.mp3`.
* Так как мобильные и десктопные браузеры блокируют звук без действия пользователя, при входящем сигнале перекрывать экран полноэкранным оверлеем:
* Если прислал админ: *"Внимание! Запущен глобальный Социальный Будильник TimeNation..."*
* Если прислал пользователь: *"[Имя Пользователя] приглашает вас к участию в Социальном Будильнике!..."*
* Ниже текст на нужном языке (из 24 доступных): *"Нажмите в любой точке экрана, чтобы включить звук Гимна!"*.


* Клик по экрану снимает блокировку аудиоконтекста и запускает трек. На оверлее обязательно должна быть кнопка «Отключить звук/Выйти».
