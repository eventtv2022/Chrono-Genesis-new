# REPLIT ACTUATOR: DEBUG & FIX CHRONOPEDIA MAP EVENT DISPLAY

## 1. CONTEXT & BUG DESCRIPTION

События (или ноды) Хронопедии не отображаются на карте Leaflet в компоненте WebView. Проблема локализована в одной из трех точек:

1. Отсутствие валидных координат `latitude`/`longitude` из-за сбоя парсинга короткого Plus Code (не передаются опорные координаты региона Фамагусты/Кипра).
2. Падение скрипта внутри WebView из-за неэкранированных спецсимволов и кавычек в JSON-строке описания событий при передаче через `postMessage`.
3. Ошибочная фильтрация бэкенда по флагам `isSimulatorAgent` или `nodeStatus`.

## 2. REPAIR INSTRUCTIONS FOR REPLIT AGENT

> *"Агент, необходимо срочно исправить отображение маркеров событий на карте Хронопедии. Пройди по всей цепочке данных и примени исправления:
> **Шаг 1: Проверка парсинга Plus Code (`components/chronopedia-map-html.ts` или сервис геокодинга):**
> Убедись, что при декодировании коротких Plus Code (например, `4WHF+GW5`) алгоритм `open-location-code` ВСЕГДА использует дефолтные опорные координаты Кипра (Широта: 35.11, Долгота: 33.95), если контекст города — Фамагуста. Если координаты на выходе получаются `null` или `0`, принудительно пиши дефолтную геолокацию посольства, чтобы маркер не исчезал.
> **Шаг 2: Безопасный мост WebView (`components/ChronopediaMap.native.tsx`):**
> Найди место, где массив событий из базы данных сериализуется в JSON для отправки в карту через `webview.postMessage()`. Из-за кавычек и переносов строк в текстах ИИ-аудитора JavaScript внутри WebView падает.
> Примени жесткое экранирование:
> ```typescript
> const safeEventsJson = JSON.stringify(events).replace(/\\/g, '\\\\').replace(/'/g, "\\'");
> 
> ```
> 
> 
> Добавь внутрь HTML-кода Leaflet обработчик `window.onerror`, который через `window.ReactNativeWebView.postMessage` вернет ошибку в консоль Expo, если JS на карте упадет.
> **Шаг 3: Проверка бэкенд-фильтров (`routes/embassies.ts` / `routes/events.ts`):**
> Проверь SQL-запрос (Drizzle), отдающий точки для карты. Временно отключи жесткий фильтр `WHERE nodeStatus = 'online'` и `WHERE isSimulatorAgent = false`, чтобы мы могли видеть созданные тестовые и симулированные события на этапе отладки. Достаточно оставить статус `'pending_verification'`.
> Выполни исправления, запусти сборку через `npm run typecheck` и выведи в лог подтверждение: "Карта Хронопедии: данные экранированы, координаты верифицированы"."*
