## 🚀 Промт для Replit: Создание и вывод Tax Pool в Админ-Панели

```markdown
# TASK: Create State Treasury / Tax Pool Dashboard in Admin Panel

## OBJECTIVE
Create an Administrative Treasury Module (`/admin/treasury` or inside the existing Admin Dashboard) to monitor the collected 2% State Tax Pool (from Auctions, Paid Consultations, and Escrow Fees) in real time.

---

## REQUIREMENTS TO IMPLEMENT

### 1. Database Schema Update (`treasury_logs.ts` or `tax_pool`)
Ensure all system taxes are collected into a dedicated structure or aggregate view:
- **Table/Entity**: `state_tax_logs`
  - `id` (UUID / Serial)
  - `sourceType` (Enum: `'AUCTION_TAX'`, `'PAID_SESSION_TAX'`, `'ESCROW_FEE'`)
  - `amount` (Decimal/Float, amount in Darmins)
  - `fromCitizenId` (FK to `citizens`)
  - `referenceId` (FK to auction/paid_session/deal ID)
  - `createdAt` (Timestamp)

### 2. Admin API Endpoint (`GET /api/admin/treasury/stats`)
Create an authenticated admin route returning:
- `totalTaxCollected` (Sum of all 2% tax entries in Darmins).
- `todayTaxCollected` (Tax collected in the last 24 hours).
- `taxBySource` (Breakdown: Auctions vs Paid Consultations vs Escrow Fees).
- `recentTransactions` (List of the last 50 tax contributions with Citizen number, amount, and timestamp).

### 3. Admin UI View (`AdminTreasuryCard.tsx` / Admin Dashboard Page)
Add a visual State Vault / Tax Pool widget to the Admin Panel:
