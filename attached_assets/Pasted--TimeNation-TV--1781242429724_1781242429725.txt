# REPLIT ACTUATOR: BUGFIX — SYNCHRONIZE VIDEO RENDERING WITH CHRONOS GRID & SCHEDULE

## 1. THE PROBLEM

В модуле **TimeNation-TV** пользователь успешно выбирает минуту на таймлайне, вводит смысл (текст), запускает генерацию, и видеокапсула успешно рендерится (генерируется файл `.mp4`). Однако после этого забронированный слот **не появляется** в компонентах `СЕТКА ЭФИРА (CHRONOS GRID)` и `Расписание эфира`. Связь между балансом Дарминов из вкладки **Казначейство**, генерацией видео и финальным апдейтом эфирной сетки нарушена.

## 2. REPAIR ARCHITECTURE & STATE MACHINE

Необходимо перевести логику бронирования слота на 3-этапную статусную модель:

1. `PENDING_RENDER` — Слот зарезервирован под генерацию, Дармины («минуты») временно заморожены на балансе гражданина.
2. `RENDERED` — Капсула готова (доступна кнопка «Открыть MP4»).
3. `PUBLISHED` — Финальный статус. Видео привязывается к UTC-индексу сетки, Дармины окончательно списываются, слот отображается в расписании.

## 3. BACKEND FIXES (FastAPI Logic)

### А. Модификация эндпоинта завершения рендеринга:

В функции, которая вызывается по окончании генерации видео (или по нажатию кнопки «Забронировать слот» после рендера), необходимо добавить принудительный вызов обновления сетки:

```python
@app.post("/api/v1/tv/confirm-slot")
async def confirm_slot_booking(citizen_id: int, utc_minute: int, video_url: str, db=Depends(get_db)):
    # 1. Проверяем баланс Дарминов (из Казначейства)
    citizen = db.query(Citizen).filter(Citizen.id == citizen_id).first()
    if citizen.darmin_balance < 1:
        raise HTTPException(status_code=402, detail="Недостаточно Дарминов на балансе")
        
    # 2. Списываем 1 Дармин (1 минута эфира)
    citizen.darmin_balance -= 1
    
    # 3. Создаем/обновляем запись в расписании эфира
    new_mrz_slot = BroadcastSlot(
        citizen_id=citizen_id,
        minute_index=utc_minute, # Значение от 0 до 1439
        video_path=video_url,
        status="published",
        timestamp=datetime.utcnow()
    )
    db.add(new_mrz_slot)
    db.commit()
    
    return {"status": "success", "message": f"Слот {utc_minute} успешно опубликован в Сетке Эфира"}

```
