Реализовать рефакторинг таблиц для группировки мнений.
Вот обновленный, комплексный промт для вашего Replit-агента, который решает технический баг с картой и внедряет архитектуру множественных исторических точек зрения:
REPLIT ACTUATOR: CHRONOPEDIA MULTI-PERSPECTIVE ENGINE & FIX MAP WEBVIEW
1. OBJECTIVE
Исправить баг React Native WebView does not support this platform в модуле Хронопедия и полностью переработать архитектуру данных под концепцию «Time & Space» с поддержкой множественности мнений граждан на одну и ту же пространственно-временную точку.
2. DATABASE ARCHITECTURE (Drizzle ORM)
Разделить физические координаты времени/пространства и субъективные тексты граждан на две связанные таблицы:
Таблица Пространственно-Временных Точек (chronopedia_slots):
id: serial / uuid (Primary Key)
time_marker: timestamp / text (метка времени/дата)
place_id: text (Google Places ID для однозначной гео-привязки)
geo_lat, geo_lng: double precision (точные координаты для карты)
location_name: text (красивое название места)
Индекс: Уникальный составной индекс по (time_marker, place_id), чтобы исключить дублирование физических слотов.
Таблица Мнений/Событий Граждан (chronopedia_events):
id: serial / uuid (Primary Key)
slot_id: references chronopedia_slots.id (связь с физической точкой)
author_id: references citizens.id (автор версии события)
title: text (название версии)
description: text (суть/смысл происходящего по мнению этого гражданина)
status: enum('pending', 'approved', 'disputed', 'deleted') (default: 'pending' для системы модерации сообществом)
3. FIXING MAP & INTERACTION LOGIC (React / Expo)
Map Fix: Замени компонент, вызывающий ошибку WebView. Если приложение рендерится в вебе/браузере (судя по expo.pike.replit.dev), используй прямую интеграцию карт через react-leaflet или чистый Google Maps JS API вместо тяжелых нативных WebView-компонентов, которые не поддерживаются текущим окружением платформы.
UI Множественности: При клике на маркер карты или точку таймлайна система должна запрашивать из базы список всех событий, привязанных к данному slot_id. Отображай их в виде вкладок (Tabs) или раскрывающегося списка: "Нажмите маркер, чтобы прочитать мнения".
