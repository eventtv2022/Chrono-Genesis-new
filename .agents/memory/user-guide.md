---
name: In-app user guide
description: Placement decision for the full TimeNation guide on mobile and web.
---

The full guide should remain accessible from the mobile Profile section and the web navigation. The web version may reuse the mobile Markdown source so content stays in sync.

**Why:** the user chose persistent access in both app versions so citizens can reopen the complete manual whenever needed.

**How to apply:** Keep the guide link in mobile Profile and web navigation when reorganizing either; contextual hints may complement but should not replace the full guide.
